# 🚀 Ashish Gautam | Developer Portfolio

Welcome to my personal developer portfolio! This is a high-performance, interactive, and visually stunning web application built to showcase my skills, projects, and achievements as a Software Developer.

🔗 **Live Portfolio:** [https://my-portfolio-mauve-gamma-49.vercel.app/](https://my-portfolio-mauve-gamma-49.vercel.app/)

---

## 💻 Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Architecture:** Component-driven design with centralized data management

---

## ✨ Key Features

- **Interactive UI:** A highly dynamic interface featuring glassmorphism, glowing borders, and HTML canvas particle background effects.
- **Floating Terminal:** A fully functional, interactive terminal widget that accepts commands (e.g., `help`, `skills`, `projects`, `clear`).
- **Data-Driven Architecture:** All portfolio content (projects, skills, education) is decoupled from the UI components and powered by a single `resumeData.js` file, making future updates incredibly simple.
- **Custom Cursor & Smooth Scrolling:** Features a customized lagging ring cursor and a gradient scroll progress bar.
- **Theme Support:** Fully responsive Dark/Light mode implementation using Context API and CSS variables.
- **SEO Optimized:** Complete HTML meta tags, Open Graph cards, and accessibility features built-in.

## 🛠️ Local Development

To run this project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/ashishsps20/<YOUR-REPO-NAME>.git
   cd <YOUR-REPO-NAME>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 📂 Project Structure

```text
src/
├── components/          # Reusable UI components (Hero, Navbar, Projects, etc.)
├── context/             # React Context providers (ThemeContext)
├── data/                # Contains resumeData.js (All textual content lives here)
├── App.jsx              # Main application layout and intersection observer logic
├── index.css            # Global CSS variables and design system tokens
└── main.jsx             # React entry point
```
